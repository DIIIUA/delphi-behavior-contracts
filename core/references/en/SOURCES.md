# Primary sources

The modern baseline is the official RAD Studio 13 Florence Language Guide and release notes 13.2. The cross-check date is 18 November 2026. This is an authored book: it does not contain a downloaded copy of the Embarcadero guide.

Each chapter identifies specific primary-source pages. Their substantive sections were checked during the work, rather than only their search-result headings. Some presumed addresses (for example Generic_Methods,Compiler_Directives) are unavailable/do not exist; the actual sections Declaring_Generics and Delphi_Compiler_Directives_(List)_Index were used instead. These access failures are not recorded as documentation that was read.

The pages contain historical limitations and some inaccuracies. For example, Program_Control reproduces x86 registers under some platform subheadings; the book does not use that passage as an x64/ARM ABI. Variables describes classic declarations, whereas Inline_Variable_Declaration describes the extension introduced in 10.3. Version contradictions are checked against the actual compiler/RTL.
