# Additional options: what has been established

> **[DEMO EDITION — Evaluation Sample]** This package is the free evaluation demo of **Delphi Behavior Contracts v1.0.2** (full corpus: 74 complete EN/RU chapters, 89 full directive cards, 879+ compiler observations). The complete original Table of Contents, verification record, working plugins, pure skills, and local/self-hosted MCP Code Mode server are included so you can inspect coverage and test the offline workflow on your own Delphi tasks. Project page: https://silentfish.dev/delphi


The names come from the Option OPT/IFOPT tables.
A listing confirms a mention, but by itself specifies neither target, default, nor effect.

| Name | Confirmed evidence | What remains unknown |
|---|---|---|
| MAXPAGESIZE | 12.3 release notes describe syntax, Android defaults, DPR/DPK, and the external linker | Actual application in a particular build has not been measured |
| VARPROPSETTER | Type Library Import explains the setter/var ABI and ON in the importer | General default/full target matrix and COM verification |
| UNSAFECODE | The official E2395 heading links an unsafe procedure to ON | Exact historical/current target semantics do not follow from this short page |
| STACKCHECKS | Option OPT lists the name and S+/S-; the main page shows S- in a group | Effect and support matrix; a Talk-page comment was not accepted as a normative contract |
| OLDOBJWARN | Option OPT lists the name beside E+/E- | Full grammar, purpose, versions, and interaction with other E forms |
| AUTOBOX | An ON/OFF form is listed in Option OPT | No independently confirmed contract for the current native compiler was found |
| NATIVE_CPP_INTERFACES | The name appears in Option OPT and IFOPT | The exact ABI effect, default, and targets have not been inferred from the name |
| COMPATIBLELITERALS | The name appears in Option OPT and IFOPT | Exactly which literal conversions change and in which versions |
| DUPLICATEENABLE | The name appears in Option OPT and IFOPT | Which operation allows duplication, the default, and scope boundaries |

MAXPAGESIZE and VARPROPSETTER now have separate cards and are included
in the confirmed base list. The other seven have not been given invented
descriptions merely to “close” a counter. Failure to find a complete
page is not proof that an option does not exist.
