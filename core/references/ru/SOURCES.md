# Первичные источники

Современная база: официальный Language Guide RAD Studio13 Florence и
release notes13.2. Дата сверки —18 ноября2026. Это авторская книга:
здесь нет скачанной копии руководства Embarcadero.

Каждая глава указывает конкретные первичные страницы. Во время работы
проверены их содержательные разделы,а не только поисковые заголовки.
Часть предполагаемых адресов (например Generic_Methods,Compiler_Directives)
недоступна/не существует; вместо них использованы действительные разделы
Declaring_Generics и Delphi_Compiler_Directives_(List)_Index. Эти ошибки
доступа не подписаны как прочитанная документация.

В страницах есть исторические ограничения и отдельные неточности. Например,
Program_Control воспроизводит x86-регистры в некоторых platform-подзаголовках;
книга не использует этот фрагмент как x64/ARM ABI. Variables описывает
классические объявления,а Inline_Variable_Declaration — расширение10.3.
Версионные противоречия проверяют по actual compiler/RTL.
