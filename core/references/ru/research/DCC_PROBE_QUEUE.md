## Сначала идентифицировать среду

Сохранить compiler version, edition, target, полную команду, working directory,
RTL/search/include paths, defines, source hashes и фактические diagnostics.
По официальным страницам `dcc32 -h`/`dcc64 -h` показывают help. Успешный help
сам по себе не подтверждает возможность компиляции или правильный target.

Host32/64 и Win32/Win64 output — разные оси. Начать с минимального scalar DPR,
скомпилировать и запустить его в изолированном каталоге. Затем выбирать
подходящие example IDs: например, 55 предназначен только для Win64.
Файл из другого release или прошлого build не подменяет новый receipt.
