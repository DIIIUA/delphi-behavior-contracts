# Дополнительные опции: что установлено отдельно

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.1** (в полной версии: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы ваш ИИ мог сразу проверить инструмент на практике и честно сказать, подходит ли вам полная версия. Полная версия: https://silentfish.dev/delphi


Перечень взят из Option OPT/IFOPT. Присутствие имени в этой таблице
подтверждает упоминание,но само по себе не задаёт target,default и эффект.

| Имя | Подтверждённое свидетельство | Что остаётся неизвестным |
|---|---|---|
| MAXPAGESIZE |12.3 release notes описывают syntax,Android defaults,DPR/DPK и external linker | Реальное применение в конкретной сборке не измерено |
| VARPROPSETTER | Type Library Import объясняет setter/var ABI и ON у импортёра | Общий default/полная target matrix и COM-проверка |
| UNSAFECODE | Заголовок официальной E2395 связывает unsafe procedure с ON | Точная историческая/современная target-семантика из этой короткой страницы не следует |
| STACKCHECKS | Option OPT перечисляет имя и S+/S-;основная страница показывает S- в группе | Эффект и support matrix;комментарий на Talk-странице не принят за нормативный контракт |
| OLDOBJWARN | Option OPT перечисляет имя рядом с E+/E- | Полная grammar,назначение,версии и взаимодействие с другими E-формами |
| AUTOBOX | Перечислена ON/OFF форма в Option OPT | Самостоятельный подтверждённый контракт current native compiler не найден |
| NATIVE_CPP_INTERFACES | Имя есть в Option OPT и IFOPT | Точный ABI эффект,default и targets не восстановлены из названия |
| COMPATIBLELITERALS | Имя есть в Option OPT и IFOPT | Какие именно literal conversions меняются и в каких версиях |
| DUPLICATEENABLE | Имя есть в Option OPT и IFOPT | Какая операция допускает дублирование,default и границы действия |

MAXPAGESIZE и VARPROPSETTER теперь имеют отдельные карточки и включены
в подтверждённый базовый список. Остальные семь не получили придуманных
описаний только ради «закрытого» счётчика. Отсутствие найденной полной
страницы не является доказательством несуществования опции.
