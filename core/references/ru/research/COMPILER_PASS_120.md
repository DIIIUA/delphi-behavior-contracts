## Метод и предел

Использован настоящий Delphi 13 Community Edition, IDE file version
37.0.60542.8024. Синтетические проекты собраны штатным действием IDE Build
через MCP2Delphi; коммерческие CLI-ограничения не обходились. На каждую пробу
создан отдельный каталог и ProjectGuid. Перед сборкой бинарного результата
в каталоге не было. Записаны исходник, DPROJ, все вспомогательные входы,
их SHA-256, профиль из сообщений сборки, событие для своего проекта,
диагностика, хэш нового PE, целевая машина и отдельный результат запуска.

Из-за установочного эвристического правила Windows для имени с Dispatch
EXE запускались как побайтно идентичная копия RunFixture.exe; повышения
прав не требовалось. Negative/control ветви не исполнялись. Успех RPC/IDE
summary сам по себе не принимался за успех компилятора.
