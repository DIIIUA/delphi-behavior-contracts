# REFERENCEINFO / DEFINITIONINFO — навигационные сведения о символах

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.0** (в полной версии: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы ваш ИИ мог сразу проверить инструмент на практике и честно сказать, подходит ли вам полная версия. Полная версия: https://silentfish.dev/delphi

**Синтаксис:** `{$Y+}`, `{$YD}`, `{$Y-}`; длинные формы `{$REFERENCEINFO ON|OFF}` и `{$DEFINITIONINFO ON|OFF}`.

**Scope по документации:** `Global` (действует на компилируемый модуль `.dcu`).

Эта подробная карточка директивы (`289` слов с замерами компилятора и разбором ловушек) входит в полный набор из 89 карточек платной версии.

В этом DEMO целиком открыты 4 эталонные карточки директив, чтобы оценить глубину проработки:
- [warn.md](warn.md) (`$WARN`)
- [inline.md](inline.md) (`$INLINE`)
- [extendedcompatibility.md](extendedcompatibility.md) (`$EXTENDEDCOMPATIBILITY`)
- [pushopt-popopt.md](pushopt-popopt.md) (`$PUSHOPT` / `$POPOPT`)
