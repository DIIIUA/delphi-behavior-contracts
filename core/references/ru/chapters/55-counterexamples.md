# 55. Контрпримеры для проверки понимания

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.2** (полный корпус: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы можно было проверить технический охват и офлайн-работу инструмента на ваших задачах по Delphi. Страница проекта: https://silentfish.dev/delphi

Эта глава **входит полностью в платную редакцию** (`1,197` слов, `120` строк).

## Разделы, разобранные в полной главе

- 1. Динамический массив без COW против `UnicodeString` с COW
- 2. Три случая потери короткого замыкания при `{$B-}`: `Variant`, `LogicalAnd` и `IfThen`
- 3. Поверхностная копия `record` с объектной ссылкой
- 4. Однократная фиксация границы `for` и беззнаковый `0 - 1`
- 5. Полиморфный `override` против статического скрытия метода
- 6. Зеркальная асимметрия частичного сбоя: `TObject.Create` против `CMR.Initialize`
- 7. Почему `SizeOf(Ev)` вызывает функцию вместо измерения указателя (`P6` / `P7`)
- 8. Тихое предупреждение `W1074` на неизвестном атрибуте и висячий `with Arr[I]`
- 9. Три иллюзии «значения по умолчанию» и внутренний `#0` в `PChar`
- Самодостаточный пример (`program ... end.`)
- Первоисточники и статус подтверждения
