# 53. Низкоуровневые и исторические формы

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.2** (полный корпус: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы можно было проверить технический охват и офлайн-работу инструмента на ваших задачах по Delphi. Страница проекта: https://silentfish.dev/delphi

Эта глава **входит полностью в платную редакцию** (`1,720` слов, `136` строк).

## Разделы, разобранные в полной главе

- 1. Три класса исторических конструкций при аудите кода
- 2. Систематический путеводитель по унаследованным формам
- Конструкции с действующей семантикой памяти в Delphi 13
- Специальные квалификаторы диспетчеризации и рудименты 16-битной эпохи
- 3. Специальные встроенные имена (`Special Builtins`) и их границы
- 4. Защита от ложных аналогий и правило сохранения внешнего ABI
- 5. Самодостаточный пример: инспекция исторических пластов на Delphi 13

## Адресованные темы главы

- `obsolete directives`
- `legacy memory forms`
