# 66. Package graph и воспроизводимая сборка

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.1** (в полной версии: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы ваш ИИ мог сразу проверить инструмент на практике и честно сказать, подходит ли вам полная версия. Полная версия: https://silentfish.dev/delphi

Эта глава **входит полностью в платную редакцию** (`1,173` слов, `107` строк).

## Разделы, разобранные в полной главе

- 1. Инвариант графа пакетов (`.dpk`): `contains`, `requires` и управляющие директивы
- 2. Механика `{$WEAKPACKAGEUNIT}` (`WEAK_PACKAGE_STATE_SCOPE`) и проба `P5`
- Запрет глобального состояния (`WEAK_PACKAGE_STATE_SCOPE` -> `DOCUMENTED_RULE`)
- 3. Декорирование имён выходов (`LIBRARY_NAMING_DEFAULTS`), проба `P11_LibNaming_Dll32` и граница `.dpk`
- 4. Самодостаточный пример (бесстатусное ядро расчёта без глобальных данных)
- 5. Границы версий и защита от ложных аналогий
- 6. Первоисточники и статус подтверждения
- Модуль для сборки пакета из начала главы

## Адресованные темы главы

- `package designation vs unit placement`
- `weak state restrictions`
- `implicit rebuild`
- `decorated image vs DCP`
- `artifact consumer proof`
