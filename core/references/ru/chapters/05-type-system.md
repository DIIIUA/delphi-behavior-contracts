# 05. Типы, идентичность и совместимость

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.2** (полный корпус: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы можно было проверить технический охват и офлайн-работу инструмента на ваших задачах по Delphi. Страница проекта: https://silentfish.dev/delphi

Эта глава **входит полностью в платную редакцию** (`1,878` слов, `143` строк).

## Разделы, разобранные в полной главе

- Номинальная типизация и ловушка безымянных объявлений
- Псевдоним (`TCount = Integer`) против выделенного типа (`TOrderId = type Integer`)
- Три уровня отношений типов и правила приведения
- Физика памяти: значения, ссылки и разделяемые буферы
- Проверенный контраст разделяемого буфера динамического массива
- `SizeOf`: размер представления переменной и платформенные сдвиги
- Самодостаточный авторский пример идентичности и `SizeOf`
- Первоисточники и статус подтверждения

## Адресованные темы главы

- `type identity`
- `type alias vs distinct type`
- `assignment compatibility`
- `value vs reference`
- `SizeOf`
