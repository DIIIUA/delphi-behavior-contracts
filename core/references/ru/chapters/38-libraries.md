# 38. library, package и внешние символы

> **[DEMO-РЕДАКЦИЯ — Ознакомительный пакет]** Это бесплатная демо-версия **Delphi Behavior Contracts v1.0.0** (в полной версии: 74 полные главы EN/RU, 89 полных карточек директив, 879+ наблюдений компилятора). Сохранено полное оригинальное оглавление, паспорт проверки, все рабочие плагины, чистые скиллы и локальный MCP-сервер с Code Mode — чтобы ваш ИИ мог сразу проверить инструмент на практике и честно сказать, подходит ли вам полная версия. Полная версия: https://silentfish.dev/delphi

Эта глава **входит полностью в платную редакцию** (`1,311` слов, `201` строк).

## Разделы, разобранные в полной главе

- 1. Назначение: три принципиально разные модульные границы
- 2. Грамматика `library`, экспорт перегрузок `exports` и импорт `external`
- Экспорт из `library` ([Export symbols](https://docwiki.embarcadero.com/RADStudio/Florence/en/Export_symbols_(Delphi)))
- Статический и отложенный импорт `external` ([External Symbols](https://docwiki.embarcadero.com/RADStudio/Florence/en/External_Symbols_(Delphi)))
- 3. Смертельная физика сырой `.dll`: изолированные кучи и дубликаты VMT
- 4. Пакеты (`package`) и границы именования выходов
- 5. Самодостаточный пример (симметричный буферный контракт границы библиотеки)
- 6. Границы версий и защита от ложных аналогий
- 7. Первоисточники и статус подтверждения
- Файл модуля для примера пакета
- Клиент, который проверяет экспортированные перегрузки

## Адресованные темы главы

- `library`
- `exports name index`
- `external delayed`
- `dynamic loading`
- `package requires contains`
- `BPL DCP dependencies`
